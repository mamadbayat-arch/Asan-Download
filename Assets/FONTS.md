# Embedded font

The application uses **Vazir Regular**, from the original publisher's v30.1.0
release: https://github.com/rastikerdar/vazirmatn/tree/v30.1.0

Source: `dist/Vazir-Regular.ttf`. The SIL Open Font License and copyright notice
are retained in `Vazir-OFL.txt` and embedded in the application resources.
Only regular weight is used; language changes preserve the same type sizes.
